# Sentiment Analysis using Machine Learning

A Machine Learning and Natural Language Processing application that analyzes text and predicts its sentiment.

## 🚀 Features

- Accepts user text as input.
- Preprocesses and cleans textual data.
- Applies Natural Language Processing techniques.
- Predicts sentiment such as Positive or Negative.
- Provides results through an interactive application interface.

## 🛠️ Technology Stack

- Python
- Machine Learning
- Natural Language Processing (NLP)
- Scikit-learn
- Pandas
- NumPy

## 🧠 How It Works

1. Text data is collected as input.
2. The text is cleaned and preprocessed.
3. The trained Machine Learning model analyzes the processed text.
4. The application predicts the sentiment.

## ⚙️ Installation

```bash
git clone https://github.com/Naresh150805/Sentiment-Analysis-ML.git
cd Sentiment-Analysis-ML
python -m venv venv
```

Activate the virtual environment and install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Project

```bash
python app.py
```
